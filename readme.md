Se instalo plant uml directamente en antigravity en lugar de usar la pagina web. con el objetivo de poder generar los diagramas directamente desde el entorno de desarrollo. 

Se utilizo la libreria plantuml-stdlib/C4-PlantUML para poder generar los diagramas siguiendo los estándares de C4, esto nos permitio crear diagramas mas limpios y estructurados.

se debe tener java instalado en la maquina para que antigravity pueda utilizar plantuml. de igual forma se debe descargar cierta version de plantuml y ponerla en .jar desde los settings de la extension. 

por ultimo descargar brew install graphviz y se podran visualizar los diagramas correctamente.# Pagolingo
